# Cinematic production record

Built-in image generation, reference edits; selected masters copied into assets/masters. Original generated files left intact. No CLI fallback or API key used.

Shared brief: photoreal Southern California exterior craftsmanship commercial, golden-hour lighting, one single-story Spanish-modern residence, terracotta roof, two bronze windows, right-hand entry, ivory stucco, low retaining wall and olive foliage. Slow architectural camera language, tactile material, no typography. Same craftsman: short dark hair, navy work shirt, tan work trousers, clear eye protection, white gloves, steel trowel and hawk. Working, never posed.

opening.png establishes cracked/weathered stucco. preparation.png reference-edits opening into barrier, flashing and lath while keeping registered architecture/camera. craftsman.png edits preparation with the working tradesman. application.png references property and worker, working from the access path with applied stucco and remaining work strip. wet-detail.png references application: bronze window, navy sleeve, white glove and rectangular steel trowel pressed flat into fresh material. finished-detail.png edits that exact macro frame: remove arm/tool and finish uniform fine-sand texture while preserving window, reflections, light and composition. final.png reference-edits the opening property into its completed facade.

mobile-final.png intentionally recomposes the same property in portrait. mobile-work.png edits that portrait with the same worker/wardrobe. The two portrait masters create the mobile film with controlled camera movement and a dissolve.

logo-restored.png edits the supplied original: preserve angular silver/navy crown, exact IMPERIAL CROWN / LATH & PLASTERING wording and true alpha transparency. Original logo retained.

Visual inspection reviewed continuity, tool geometry and tactile texture. A discarded crown variation and redundant 4K-requested image are not integrated. Actual landscape output:1672x941; portrait:941x1672. This is an illustrative keyframe commercial, not native 4K footage or claimed client-project documentation. Real projects are separate.
